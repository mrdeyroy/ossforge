# Credits

ossforge is an independent implementation that builds on ideas from:

- [GitSense](https://github.com/he-yufeng/GitSense) (MIT): repo health scoring thresholds and the PR merge-likelihood
  heuristic were adapted into `radar.py` and `predictor.py`.
- [oss-scout](https://github.com/costajohnt/oss-scout) (MIT): the anti-AI policy keyword table in `policy.py`, and the
  approach to issue vetting, search budgeting and caching.
- [ContribAI](https://github.com/tang-vu/ContribAI) (AGPL-3.0-or-later): conceptual inspiration only (consent-first
  contribution, protected paths, evidence log, PR patrol). No ContribAI source code is included.

Thanks to their authors.
